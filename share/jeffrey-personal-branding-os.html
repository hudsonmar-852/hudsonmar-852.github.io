1｜先改一個最重要嘅觀念：GP 係場景，唔係終身身份

Jeffrey，而家你喺 GP Fitness 教班，呢一刻係一個工作場景，但唔應該成為你嘅終身身份。Gym 可以裝修、改革、換管理層、改佣金制度甚至改定位；但你同客人建立嘅信任、你處理客人問題嘅方法、你累積嘅經驗同口碑，先係真正屬於你。

所以由今日開始，每做一個客，都唔好淨係問：「今個月可以 sell 幾多堂？」應該多問一句：「呢個客完成三個月之後，我有冇真正幫到佢？我有冇一套記錄證明？佢會唔會願意繼續跟我，甚至介紹朋友？」

Jeffrey 今日可以做：由下一位新客開始建立 Client Profile；唔需要一次過改晒所有舊客。先做好一個，再複製。

2｜重新定位：由 PT → Personal Wellness & Performance Coach

PT 容易令人聯想到「買幾多堂、操幾重、減幾多磅」。Jeffrey 更值得建立嘅定位係 Personal Wellness & Performance Coach：唔係只負責一小時訓練，而係幫客人管理由現況到目標嘅整個改善過程。

Assessment → Goal → Programme → Coaching → Tracking → Follow-up → Review → Adjustment → Relationship → Referral

客人最記得未必係你叫佢推過幾重，而係你隔幾日仍然記得：「你上次話膝頭哥屈落去唔舒服，而家好啲未呀？」嗰一下先令客人覺得：「呢個教練真係知道我發生緊咩事。」

對新客介紹自己：唔需要刻意講一大堆 title。可以自然講：「我唔係淨係睇你今日操咩，我會一路記住你嘅目標同身體反應，再按進度幫你調整。」

3｜Assessment：第一堂唔係急住 Sell，而係真正了解個人

Assessment 係 Coaching OS 第一個入口。除咗基本身體狀況，Jeffrey 應該理解客人真正想改善嘅生活問題：點解而家先想開始？最大阻力係時間、痛楚、信心、體重，定係以前試過但維持唔到？

要了解例子
真正目標減脂、力量、活動能力、外觀、自信、日常舒服程度
生活模式Office 時間、睡眠、壓力、出差、家庭責任
過往經驗以前做過咩、點解停、最唔鍾意咩
限制已知傷患、痛楚、活動限制；需要時建議尋求合資格醫療專業意見
成功定義三個月後客人覺得咩改變先算值得
可以問：「如果三個月之後你覺得今次真係有幫助，你最想見到自己有咩改變？」
Jeffrey 建議：Assessment 完唔好只記重量、體脂。最少留低「Goal / Main Concern / Lifestyle / Limitation / First Priority」五項。

4｜Goal Setting：將「想 Fit 啲」變成真正可以管理嘅方向

好多客人最初只會講「想瘦」、「想大隻」、「條腰成日攰」。Jeffrey 嘅價值係幫佢將模糊願望變成一個雙方都理解嘅方向，同時避免承諾不合理結果。

Outcome Goal

客人最終想得到嘅改變。

Process Goal

每星期實際做到嘅行為，例如訓練頻率、步行或恢復習慣。

每次定目標：最好同時有「想得到咩」＋「每星期做咩」＋「幾時 review」。咁客人唔會只盯住磅數。

5｜Programme Design：每堂有原因，而唔係每堂臨場諗

Programme 唔需要複雜到似運動科學論文，但 Jeffrey 自己要知道每一階段點解咁安排。客人應該感受到前後有連貫性，而唔係今日見到邊部機得閒就做邊部。

基本可以分：建立動作質素與適應 → 漸進負荷／能力 → 針對目標 → Review / Deload / Adjustment。實際內容要按個別客戶能力及專業範圍決定。

每個 Programme 最少寫低：目前階段、主要目標、核心動作／能力、progression 原則、需要留意嘅限制、下一次 review 日期。

6｜Session Log：每堂完 1–2 分鐘，建立你最有價值嘅記憶

唔需要 Jeffrey 每晚做大量文書。每堂只要有一個極簡紀錄，就可以令下一堂嘅服務質素完全唔同。

Today → Response → Issue → Next Step → Personal Note
Today今日主要做咗咩／大概負荷
Response表現、感覺、RPE 或可觀察反應
Issue今日有冇不適或困難
Next Step下一堂加、減、維持或改咩
Personal Note例如下星期出差、工作忙、提過膝頭問題
真正價值：下一堂見到客之前用 20 秒睇返最後一條 note，就可以自然問返上次嘅事。呢個就係「科技幫 Jeffrey 保留人情味」，而唔係 CRM 取代人情味。

7｜Weekly Check-in：堂與堂之間，客人仍然感受到有人跟

Weekly check-in 唔係每日追住客人，更唔應該變成 broadcast。目的係在適當時間確認進度、障礙同需要。

「上次你話呢排返工比較忙，呢幾日個人點呀？膝頭／腰嗰邊有冇好啲？下次返嚟我哋再按情況調整。」

對穩定客戶未必每星期都需要長訊息；頻率應按客戶需要同雙方習慣。

Jeffrey 建議：每次訊息至少有一個「只屬於呢個客」嘅 context。避免：「Hi 最近好嗎？記得運動！」呢類任何人都收到嘅訊息。

8｜Monthly Review：唔好等到堂數用完先突然講續堂

每月／每個 training block 做短 review，目的係俾客人睇到自己由 A 去到邊度，而唔係到最後兩堂先突然 sell package。

Review問題
Progress今個月有咩實際改善？
Experience客人自己覺得最大分別係咩？
Obstacle邊樣最阻住進度？
Adjustment下個月需要改咩？
Next Milestone下一個值得追嘅成果係咩？
「我哋唔好淨係睇體重。你自己覺得呢一個月，邊樣係最明顯改善咗？」
續堂思維：如果客人清楚睇到 Progress → Next Goal → Why Continued Coaching Helps，續堂會比突然 hard sell 自然得多。

9｜Personal Care：最難被其他教練複製嘅部分

Jeffrey 唔需要扮朋友，亦唔需要過度介入私人生活。真正高質嘅 Personal Care 係記得與 coaching 有關、而客人曾經主動分享嘅重要 context，並在適當時候 follow up。

例如工作突然忙、旅行後重新開始、之前某動作唔舒服、最近睡眠差。呢啲資訊令 programme 真正變成「為呢個人而設」。

原則：關心要真、要有 context、要有界線。唔好為咗 CRM 而問；有實際 coaching 意義先記。

10｜Progress Evidence：每個客慢慢變成一個 Case Study

Case Study 唔等於一定要 Before / After 半裸相。對 Jeffrey 嘅客群，生活改善好多時更有說服力，例如以前坐 Office 半日腰攰、而家舒服好多；以前唔敢深蹲、而家活動更有信心。

Starting Point → Plan → Process → Adjustment → Result → Client Reflection

任何公開 testimonial、相片、身體資料或可識別資訊，都應先取得客戶清楚同意，並尊重 GP 政策及私隱要求。

Jeffrey 建議：每個月揀 1–2 個有代表性進步個案整理。唔需要全部公開；私人 case library 本身已經可以幫你改善方法。

11｜Referral：唔係「介紹朋友畀我」，而係信任自然延伸

最好嘅 referral 時機通常係客人主動講自己有進步、完成一個 milestone，或者朋友已經問佢「你最近係咪 fit 咗？」嗰刻。

「你覺得有幫助我已經好開心。如果你身邊有朋友都有類似問題，想了解下可以叫佢搵我傾吓，唔一定要即刻報堂。」
Referral Engine：Result → 客人感受到價值 → 願意分享 → 新人低壓了解 → Assessment。唔好將每次 progress review 變成 referral sales pitch。

12｜喺 GP 入面做差異化：唔需要同大量會員模式鬥平

Jeffrey 應該利用 GP 現有「身體管理／Recovery」方向，建立一個高接觸、高跟進嘅 coaching experience。Southside 願意為專業、方便、信任及服務付費嘅客群，未必最在意最低價。

差異化唔係講自己「最好」，而係客人實際體驗到：Assessment 比較完整、每堂有記錄、有人跟進、每月有 review、programme 會按生活改變。

Jeffrey 建議：先將自己 5–10 個 active clients 做到呢個標準，再用 retention、testimonial、referral 同 progress 去證明模式有效。

13｜同 GP 傾：先建立 3 個月 Value Plan

同 GP 談唔應該一開始淨係講「底薪幾多、堂費幾多」。更成熟係提出：Jeffrey 願意幫公司改善 coaching experience，同時希望成果有清晰回報。

「我唔淨係想做好一個 PT。我想試下用三個月建立一套更完整嘅 Assessment、follow-up 同 client review，睇吓可唔可以幫 GP 提升 conversion、retention 同 referral。三個月後我哋用數據 review，再傾角色同薪酬。」
KPI用途
Assessments新客入口
Assessment → PT Conversion轉化能力
Active Clients穩定客戶量
PT Revenue直接商業價值
Renewal / Retention長期價值

重要：「60 assessments、30% conversion」只可以係示例。未知道 GP baseline、客流、分配方式之前，不應當成 Jeffrey 正式承諾。

14｜薪酬談判：唔好只用「我好辛苦」做理由

辛苦係真實感受，但公司談薪酬通常更容易回應可量化價值。Jeffrey 可以由「要求加人工」轉成「成果對應回報」。

Guaranteed Base + PT Performance + Retention / Renewal + Referral + Growth / Leadership
「過去三個月我嘅 active clients、renewal、referral 同 revenue 去到呢個水平。如果公司覺得呢個方向有價值，我想傾下一階段個 package 同 responsibility 點樣一齊提升。」
談判前準備：一頁紙已足夠：Before / Current KPI、3 個代表 case、客戶 feedback、下一季計劃、你希望公司提供嘅回報。

15｜GP 裝修／改革／Restructure：收入保障要預先講

如果公司裝修或營運改革令客流、可教堂數或開放時間下降，而原因唔係 Jeffrey 表現，最好預先傾清楚過渡安排，而唔係發生後先處理。

  • 過渡期 guaranteed base 或最低收入安排
  • 現有客戶點樣暫時安排／保留
  • 停課期間 Jeffrey 可否負責 assessment、follow-up、content、client reactivation 或其他角色
  • 重開後 client restoration / commission 點計
  • 任何改動最好有書面確認，並按實際僱傭合約處理
「如果裝修期間堂數下降，我想預先傾清楚公司會點安排現有客同收入，咁我都可以安心幫公司做好過渡同重開。」

16｜Career Path：唔好只問「幾時加人工？」

更有用嘅問題係：「如果我想做到 Senior PT 或 Team Lead，公司希望我做到咩？」

  • 每月 PT Revenue？
  • Active Client 數？
  • Retention / Renewal Rate？
  • Referral？
  • 帶新人／trainer coaching？
  • Assessment / Customer Experience？
  • Social Media / Brand contribution？
「如果我達到呢啲指標，下一個 role、responsibility 同 salary range 會點樣對應？我哋可唔可以定一個 review date？」
Jeffrey 建議：Career Path 最重要四樣：Criteria、Evidence、Review Date、Reward。缺一樣都容易最後變成「遲啲再算」。

17｜Freelance Roadmap：唔係一年後一定走，而係一年後有得揀

唔建議因為一時收入或者情緒就急住跳 Freelance。GP 可以成為 Jeffrey 建立方法、客戶處理能力、case studies 同商業能力嘅 Build Platform。

Phase 1｜Build

做好 Coaching OS、穩定 active clients、case library、referral。

Phase 2｜Validate

確認個人品牌有人認、方法可以重複、收入模型有數據。

Phase 3｜Options

留 GP 升職、重新談條件、合法跨場合作，或者考慮 Freelance。

Phase 4｜Independent System

只有在合約、客戶來源、保險、場地、行政及現金流都清楚後先擴大獨立模式。

真正目標：唔係「逃離 GP」，而係建立 negotiation power 同選擇權。

你可能想知道……

係咪即係將 GP 客人變成自己客？

唔係。GP 客戶資料、聯絡方式、公司資源同商業關係要尊重合約、公司政策及私隱。Jeffrey 真正應該累積係能力、方法、公開作品、合法口碑同個人 reputation。

每個客都做咁多，會唔會太煩？

所以 Coaching OS 一定要極簡。每堂 1–2 分鐘 log；weekly check-in 可以短；monthly review 亦可以 5–10 分鐘。重點係 consistency，而唔係文件長度。

Revenue 定 Retention 邊個重要？

兩個都唔應單獨睇。Conversion 代表開新客能力；Revenue 代表商業結果；Retention 代表持續價值；Referral 代表信任；Progress 代表服務本身有冇做到應有價值。

幾時先真正適合 Freelance？

當 Jeffrey 有可重複方法、穩定 referral、case studies、個人品牌、基本商業及行政能力、合適保險／場地安排，以及足夠現金流安全邊際，再評估會合理好多。

唔講你唔知

  • 私人教練 business 入面，Retention 唔只係「客人鍾唔鍾意你」，亦直接影響收入穩定性同 acquisition 壓力。
  • Progress tracking 除咗幫教練調整 programme，亦可以令客人睇得見一啲體重以外嘅改善。
  • 最難複製嘅競爭優勢通常唔係一個 exercise，而係長期一致地「記得、跟進、調整、關心」。
  • 一套好 Coaching OS 最終應該令人覺得服務更有人情味，而唔係更似機械 CRM。
