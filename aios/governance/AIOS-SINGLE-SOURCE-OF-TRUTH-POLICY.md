# AIOS Single Source of Truth Policy

Status: Draft pending `P-GOV-ALIGN-001` approval

GitHub is authoritative for governance, technical architecture, code,
configuration, schemas, tests, agent instructions, executable workflows, ADRs,
Engineering Orders, registries, change logs, release definitions, and dashboard
source data.

Google Drive `Hudson AIOS` is authoritative for executive copies, research,
knowledge, meetings, reports, large/media/private assets, AI communications,
and privacy-required review packages. Mirrors identify their GitHub canonical
path and never claim technical authority.

The MacBook is a working copy. GitHub Pages is generated output. Chat history
and AI memory are never authoritative or approval records.

Each record type has one path in `aios/data/canonical-records.json`. Search
before creation. Register conflicts; never silently overwrite, delete, or move.
Drive migration requires reviewed exact IDs, permission review, rollback, and
major-change approval where applicable.
